Intelligent AgentAn agent is an entity that perceives its environment through sensors and acts upon it using actuators.Sensors: Gather percepts from the environment (e.g., location sensor, dirt sensor).Actuators: Perform physical actions in the environment (e.g., cleaner motor, wheels).2. Simple Reflex AgentA Simple Reflex Agent works on the principle of direct mapping from percepts to actions. It ignores percept history and operates purely on the current percept using Condition-Action Rules:$$\text{Percept} \longrightarrow \text{If-Then Rule} \longrightarrow \text{Action}$$Limitation: It works only in fully observable environments and can easily get stuck in infinite loops if the environment is partially observable.3. PEAS RepresentationP (Performance Measure): Cleanliness of environment, energy consumed, time taken.E (Environment): Two locations ($A$ and $B$), state of locations (Clean or Dirty).A (Actuators): SUCK, Move RIGHT, Move LEFT, NO-OP.S (Sensors): Location sensor ($A$/$B$), Dirt sensor (1 for Dirty, 0 for Clean).ALGORITHM:Start.Define the agent function taking current location and room status as parameters.Check Dirt Condition:If status == 1 (Dirty), execute action SUCK and set status = 0 (Clean).Else if status == 0 (Clean), execute action NO-OP.Check Location Condition for Movement:If location == 'A', set action to Move RIGHT and update location = 'B'.If location == 'B', set action to Move LEFT and update location = 'A'.Read initial environment inputs from the user (Agent starting location, Room A status, Room B status).Run a execution loop for 2 steps to process both locations.Output the steps, room status updates, and total path cost.Stop.
